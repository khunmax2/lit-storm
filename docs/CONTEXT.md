# Research Workspace

คำศัพท์ของระบบเว็บสำหรับทำวิจัยด้วย STORM และ Co-STORM

## Language

**Project**:
พื้นที่จัดกลุ่มงานวิจัยที่มีผู้ใช้หนึ่งคนเป็นเจ้าของ ไม่บังคับใช้ งานวิจัยไม่ต้องอยู่ใน Project ใด และย้ายเข้า ย้ายออก หรือย้ายไป Project อื่นได้ทุกเมื่อ ในรุ่นแรกเป็นพื้นที่ส่วนตัวและยังไม่มีสมาชิกที่ร่วมทำงานใน Project เดียวกัน
_Avoid_: Team workspace, Shared project, Folder (ใช้ Project)

**User**:
บุคคลที่ใช้งานระบบและเป็นเจ้าของ Project ส่วนตัวได้

**Administrator**:
ผู้ใช้ที่มีบทบาทดูแลระบบและจัดการบริการค้นหาที่เปิดให้ผู้ใช้เลือก โดยเห็นข้อมูลสำหรับดูแลระบบเป็นค่าเริ่มต้นและอ่านเนื้อหางานวิจัยส่วนตัวของผู้อื่นได้เมื่อเจ้าของอนุญาต (รุ่นแรกยังไม่มีการอนุญาตนี้)

**Research Session**:
งานวิจัยหนึ่งหัวข้อ อยู่ใน Project หนึ่งหรือไม่อยู่ใน Project ใดก็ได้ ผู้ใช้กลับมาปรับโจทย์หรือขอบเขตและสั่งทำวิจัยซ้ำได้ โดยเก็บประวัติแต่ละรอบไว้
_Avoid_: Login session, Run

**Run**:
การประมวลผลงานวิจัยหนึ่งรอบภายใน Research Session โดยมีโจทย์และผลลัพธ์ของรอบนั้น การสั่งทำใหม่หลังปรับโจทย์หรือกดลองใหม่หลังงานล้มเหลวสร้าง Run ใหม่และไม่ทับผลลัพธ์เดิม
_Avoid_: Research Session

**Engine**:
วิธีทำวิจัยแบบหนึ่งที่ Run ใช้สร้าง Report เช่น STORM ในรุ่นแรก และ Agent Research กับ Deep Research ในรุ่นสอง บนหน้าจอเรียกว่า "โหมด" (Co-STORM เป็นโหมดหนึ่งแต่ทำงานเป็น Discussion ไม่ใช่ Run)
_Avoid_: Model, Runner

**Worker**:
ส่วนของระบบที่ประมวลผล Run เบื้องหลังแยกจากหน้าเว็บ Run ที่กำลังทำจะถูกขัดจังหวะเมื่อ Worker ล่ม

**Report**:
รายงานผลการวิจัยที่เชื่อมโยงกับ Run ที่สร้างรายงานนั้น รายงานจากรอบก่อนยังคงอยู่เมื่อมีการรันใหม่
_Avoid_: Article

**Discussion** (รุ่นสอง):
งานวิจัยแบบโต้ตอบด้วย Co-STORM ที่ผู้ใช้กับ Engine สนทนากันทีละรอบ (Turn) ไม่ใช่ Run ที่ทำจบในครั้งเดียว เป็น Research Session ชนิดหนึ่ง จึงอยู่ใน Project และถังขยะได้เหมือนหัวข้ออื่น และสร้าง Report ได้หลายครั้งระหว่างสนทนา
_Avoid_: Round table, Run

**Turn** (รุ่นสอง):
การสนทนาหนึ่งรอบใน Discussion ผู้ใช้พิมพ์แทรก ให้ผู้เชี่ยวชาญคุยต่อ หรือขอรายงานก็ได้ การเตรียมพื้นหลังตอนเริ่ม Discussion ก็นับเป็น Turn หนึ่ง Discussion มีจำนวน Turn จำกัดต่อหนึ่งหน่วย Quota และทำได้ทีละ Turn
_Avoid_: Step, Round

**Depth level** (ระดับความลึก, รุ่นสอง):
ความละเอียดของการค้นคว้าที่ผู้ใช้เลือกต่อ Run มี 3 ระดับคือ เร็ว, มาตรฐาน และลึก ใช้ชุดเดียวกันทุก Engine แต่ละระดับมีเป้าเวลาของตัวเอง ส่วนความหมายเชิงตัวเลขของแต่ละระดับผู้ดูแลเป็นคนกำหนด
_Avoid_: Mode (ซึ่งหมายถึง Engine ที่เลือกบนแท็บ), Short/Long

**Question refinement** (การขัดเกลาโจทย์, รุ่นสอง):
ขั้นที่เลือกได้ก่อนส่ง Run ระบบถามคำถามสั้น ๆ ให้โจทย์ชัดขึ้น แล้วคำตอบของผู้ใช้กลายเป็นส่วนหนึ่งของโจทย์ ไม่นับ Quota
_Avoid_: Feedback, Clarification step

**Project instructions** (คำสั่งของ Project, รุ่นสอง):
ข้อความที่เจ้าของ Project กำหนดให้ทุก Run ใน Project นั้น มี 2 ส่วน คือขอบเขตการค้น และรูปแบบการเขียน งานที่ไม่อยู่ใน Project ไม่มีคำสั่งนี้
_Avoid_: System prompt, Project settings (ซึ่งรวมค่าเริ่มต้นด้วย)

### แหล่งข้อมูลและหลักฐาน

**Search Provider**:
บริการหรือระบบที่ใช้ค้นหาแหล่งข้อมูลสำหรับงานวิจัย เช่น Tavily, arXiv และ SearXNG
_Avoid_: Source (ซึ่งหมายถึงแหล่งข้อมูลที่ค้นพบ ไม่ใช่บริการค้นหา)

**Source**:
แหล่งข้อมูลหนึ่งรายการ (เช่น หน้าเว็บหรือบทความ) ที่ Report อ้างอิง
_Avoid_: Search Provider, Reference

**Citation**:
เครื่องหมายอ้างอิงในเนื้อหา Report ที่ชี้ไปยัง Source

**Evidence**:
ข้อความบางส่วนจาก Source ที่ Engine บันทึกไว้และใช้จริงตอนเขียน Report ไม่ใช่ต้นฉบับเต็ม บาง Source อาจไม่มี Evidence
_Avoid_: Snippet, Quote

### การใช้งานและการดูแล

**Quota**:
จำนวนหน่วยต่อเดือนที่ผู้ใช้แต่ละคนใช้ได้ ซึ่งถูกจอง นับ และคืนตามสถานะของ Run หนึ่ง Run ใช้หนึ่งหน่วยไม่ว่าจะใช้ Engine หรือ Depth level ใด ส่วน Discussion ใช้หนึ่งหน่วยต่อ Turn หนึ่งชุด (รุ่นสอง)
_Avoid_: Credit, Limit

**Trash**:
ที่พักของ Project, Research Session หรือ Report ที่ถูกลบ กู้คืนได้ภายใน 30 วันก่อนจะถูกลบถาวร
_Avoid_: Archive

**Support Access Grant** (รุ่นสอง):
การอนุญาตจากเจ้าของให้ผู้ดูแลที่ระบุเป็นรายคนอ่านข้อมูลเฉพาะ Run ที่เลือกเพื่อช่วยตรวจปัญหา มีอายุ 24 ชั่วโมง เจ้าของเพิกถอนได้ทันที และมีประวัติการเข้าดู
_Avoid_: Project membership, Public sharing
