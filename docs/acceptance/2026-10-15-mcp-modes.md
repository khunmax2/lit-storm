**ค่าใช้จ่าย:** ราว $0.057 (งบ $0.10) คิดจากราคา Gemini 3.1 Flash Lite $0.25 / $1.50 ต่อล้าน token เพราะ `cost_usd` ของ Run ว่าง ดูหัวข้อ "พบแต่อยู่นอกขอบเขต"

สิ่งที่ตรวจในแต่ละเส้น:

- **server และ tool:** ชื่อ server เป็น "DeepLit {โหมด}" มี tool 8 ตัวที่ขึ้นต้นด้วยชื่อโหมด และ `*_start` ไม่มีพารามิเตอร์ `mode`
- **`*_options`:** เห็นเฉพาะโหมดของเส้น และโควตาเป็นโควตารวมของบัญชี (10 → 9 → 8)
- **progress:** เดินหน้าอย่างเดียว เช่น STORM 0/5 → 1/5 research → 2/5 outline → 3/5 article → 4/5 polish → 4/5 normalize → 5/5
- **`*_report`, `*_export`, `*_events`:**
  - `*_report` ส่วน outline อ่านได้
  - `*_export` แบบ md ได้ชื่อไฟล์ภาษาไทยถูกต้อง
  - `*_events` ได้ event ของ engine นั้น (Deep: `tree`, STORM: `perspectives`, Agent: `flow`)
- **`*_list`:** แสดงเฉพาะงานของโหมดนั้น
- **ส่ง id ไปผิดเส้น:** ถูกปฏิเสธ และข้อความบอกโหมดของงานพร้อมเส้นที่ถูก เช่น "That research is a STORM run, and this is DeepLit's Deep Research server: read it through DeepLit's STORM server (deeplit-storm, …)"

## หน้าเว็บ

- **หน้าการเชื่อมต่อ:**
  - ตัวเลือกเส้นมี 4 การ์ด แต่ละใบมีคำอธิบายภาษาไทย
  - snippet เปลี่ยนเป็น `deeplit-deep` / `/api/mcp/deep` ตามเส้นที่เลือก และปุ่มทดสอบเรียก `deep_research_options`
- **บัญชีเชื่อมต่อที่อนุญาตเฉพาะ Deep Research:** dialog สร้าง token แสดงเส้น STORM กับ Agent เป็นสีจาง พร้อมข้อความ "บัญชีนี้ใช้โหมดนี้ไม่ได้"
- **canvas:** ดูทั้งสาม scene กับ event จริงที่ export จาก stack (`tests/canvas_demo_server.py`) ทั้งไทย อังกฤษ และธีมมืด รายละเอียดอยู่ใน ADR-0010 ส่วนการทดสอบ

## Claude Code เลือกเส้นเอง

ต่อ `deeplit`, `deeplit-storm`, `deeplit-deep` และ `deeplit-agent` พร้อมกัน แล้วสั่งงานโดยไม่บอกว่าให้ใช้เส้นไหน (depth fast)

| คำสั่ง | Claude เลือก | ผล |
|---|---|---|
| คำถามเจาะจง: ราคาแบตโซเดียมไอออนเทียบกับ LFP ล่าสุด (อังกฤษ) | `deeplit-deep` → `deep_research_start`, `deep_research_report` | สำเร็จ 6 แหล่ง ตอบ 5 ข้อพร้อมอ้างอิง และบอกเองว่ารอบ fast มีแหล่งน้อย ถ้าต้องการตัวเลขที่น่าเชื่อถือควรใช้ standard หรือ deep |
| บทความภาพรวมเรื่องประเพณีลอยกระทง (ไทย) | เส้นรวม `deeplit` → `research_start` กับ `mode=storm` | สำเร็จ 18 แหล่ง สรุปโครงเรื่อง 6 หัวข้อพร้อมอ้างอิง |

- โหมดที่เลือกถูกทั้งสองครั้ง (คำถามเจาะจงได้ Deep บทความภาพรวมได้ STORM) แต่เมื่อมีเส้นรวมด้วย Claude อาจเลือกเส้นรวมแล้วระบุโหมดเอง
- ถ้าต้องการบังคับให้ client ใช้เส้นแยก ให้ต่อเฉพาะเส้นแยก
- ค่า LLM ของ DeepLit ราว $0.025 (Deep 5,703 / 2,646 token, STORM 22,358 / 9,050 token) และค่าใช้งาน Claude Code ราว $0.73 ซึ่งคิดกับบัญชี Claude ของเจ้าของ

## พบและแก้ระหว่างทำ

- **setup ล้นกรอบ:** ใน dialog การ์ดเลือกเส้นกับบรรทัดคำสั่งยาวล้นออกนอกกรอบ (บรรทัดคำสั่งยาวล้นมาตั้งแต่ก่อนงานนี้) แก้ให้รายการใน section หดได้ และใน dialog ใช้ 2 คอลัมน์
- **canvas ส่งความสูงสลับไปมา:** scrollbar ใน iframe โผล่แล้วหายวนซ้ำ จึงใช้ `scrollbar-gutter: stable`
- **ข้อความไม่ตรงสถานะ:** แถวหัวข้อของ Agent ระดับลึกที่จบแล้วยังเขียนว่า "กำลังเขียน" แก้ให้แสดงรอบสุดท้าย
- **ไวยากรณ์:** ข้อความปฏิเสธเคยใช้ "a Agent Research run" แก้เป็น "an" และเพิ่ม test
