## สิ่งที่ตรวจในแต่ละ Run

- **ความคืบหน้า:** stage ไล่ครบ refine → search → screen → read → synthesize ตาม event ของ MRA (32 event สำหรับถามเร็ว, 78 event สำหรับรีวิวเต็ม)
- **canvas "ดูการทบทวน":**
  - คำถามที่ MRA ตีความพร้อมข้อสมมติ
  - คำค้น 4 ข้อ พบ 354 รายการ มีบทคัดย่อ 120 รายการ คัดกรองแล้วเหลือ 26
  - การ์ดของ paper 26 ฉบับ แต่ละใบมีรูปแบบงานวิจัยและจำนวนตัวเลขที่ตรวจ
- **หน้ารายงาน:**
  - 9 หัวข้อ (ข้อค้นพบหลัก, อภิปรายผล, เปรียบเทียบงานวิจัย, จุดสอดคล้อง, จุดขัดแย้ง, ความน่าเชื่อถือ, ช่องว่าง, วิธีการ, งานวิจัยที่รวมไว้) และ 26 แหล่งอ้างอิง
  - มุมมองที่สาม "รายงานแบบเต็ม (MRA)" โหลดหน้าของ MRA ขนาด 1.46 MB ใน sandbox (`allow-scripts allow-popups`)
    - เมื่อเปิดหน้าเดียวกันโดยตรงภายใต้ sandbox เดียวกัน หน้าแสดงครบ
    - เนื้อหาในกรอบจับภาพจาก browser pane ไม่ได้ ซึ่งเป็นแบบเดียวกับมุมมองภาพที่มีอยู่แล้ว
- **MCP:**
  - `medical_research_start` ไม่มีพารามิเตอร์ `depth`, `sources` หรือ `mode`
  - `medical_research_options` บอกสถานะของ MRA และประเภทการทบทวน
  - `medical_research_report` อ่านได้ทั้ง outline และ full
- **ตัวกันเริ่มซ้ำ:** คำถามเดิมผ่าน token เดิมภายใน 10 นาทีได้ Run เดิมคืนมา โดยไม่ส่งถึง MRA

## พบและแก้ระหว่างทำ

- **key ไม่ถึง process ของ Run:** supervisor ส่ง secrets เฉพาะฟิลด์ที่รู้จัก จึงเพิ่ม `service_api_key`
- **กฎ "ห้ามปิดโหมดสุดท้าย" นับ Medical Review ที่ยังไม่ตั้งค่าเป็นโหมดที่ใช้ได้:** เปลี่ยนให้ใช้กฎเดียวกับ `modes.offered`
- **canvas ว่าง:** API ส่ง note ให้เจ้าของเฉพาะชนิดที่อยู่ในรายการ จึงเพิ่ม `medical` เข้าไป
- **การ์ด Run:**
  - ชื่อ stage ใหม่ยังไม่มีคำแปล
  - แสดง "มาตรฐาน" แทนถามเร็ว/รีวิวเต็ม
  - มีปุ่ม observatory ที่ไม่มีข้อมูลให้แสดง
- **canvas แสดงรหัสรูปแบบงานวิจัยดิบ** (`sr_ma_rct`) และ "ตรวจตัวเลข 0 ตัว": เปลี่ยนเป็นชื่อที่อ่านได้ และ "ไม่มีตัวเลขให้ตรวจ"
- **สีของทิศทางผล:** ไม่ใช้เขียวกับแดง เพราะทิศทางลบอาจเป็นผลดี เช่น เหตุการณ์ลดลง
- **สายด่วนซ้ำ:** ข้อความของ MRA มีเบอร์อยู่แล้ว จึงไม่ต่อท้ายเบอร์ที่มีอยู่ในข้อความอีก
- **Postgres, Redis และ SearXNG ของ MRA ไม่กลับมาหลัง Docker รีสตาร์ต:** upstream ไม่มี restart policy จึงเพิ่มใน `docker-compose.override.yml` ของเครื่องนี้ (อยู่ใน `.git/info/exclude` ไม่แตะไฟล์ของ MRA)
