# ภาพประกอบรายงาน: โมเดลส่ง JSON อ้างข้อเท็จจริงตามเลข ระบบตรวจแล้ววาดเอง

รายงานแบบโต้ตอบ (interactive report) มีภาพประกอบ ได้แก่ ตัวเลขสำคัญ กราฟ ลำดับเหตุการณ์ ตารางเปรียบเทียบ แผนภาพ และอภิธานศัพท์ ภาพเหล่านี้วางไว้ท้ายหัวข้อที่เกี่ยวข้อง แนวทางมาจากงานค้นคว้า `docs/research/2026-10-01-interactive-html-report.md` ซึ่งเจ้าของรับตามข้อแนะนำทุกข้อ (§8.8)

**โมเดลไม่เขียน HTML หรือ JS** ระบบตัดข้อความหลักฐาน (Evidence) ของแหล่งอ้างอิงเป็นข้อเท็จจริงสั้นๆ ที่มีเลขกำกับ (F1, F2, …) แต่ละข้อผูกกับแหล่งของมัน โมเดลตอบเป็น JSON ตาม schema แคบๆ ของเรา และทุกค่าต้องระบุเลขข้อเท็จจริงที่มา จากนั้น `litstorm.visuals` ตรวจทุกค่าโดยไม่ใช้ LLM ค่าที่ไม่ผ่านจะถูกตัดทิ้ง ไม่มีการเติมให้ ส่วน `render/interactive.py` เป็นตัววาดภาพ

## เหตุผล

- ความน่าเชื่อถือสำคัญกว่าจำนวนภาพ ตัวเลขทุกตัวในภาพต้องย้อนไปหาข้อความต้นทางได้ เหมือนเลขอ้างอิง [n] ในเนื้อหา
- ให้อ้างข้อเท็จจริงตามเลข ไม่ให้คัดลอกข้อความ เพราะโมเดลมักคัดลอกเพี้ยนนิดหน่อย ถ้าตรวจแบบตรงตัวจะต้องตัดทิ้งเกือบทั้งหมด การอ้างตามเลขทั้งตรวจได้เข้มกว่าและใช้ token น้อยกว่า
- ถ้าโมเดลส่งแค่ข้อมูล ความปลอดภัยก็ง่าย ทุกข้อความถูก escape และหน้ารันเฉพาะ script ของเราเท่านั้น

## Considered Options

- **ให้โมเดลเขียน HTML/JS เองแบบ Claude Artifacts** ไม่เลือก เพราะตรวจตัวเลขในโค้ดที่โมเดลเขียนเองไม่ได้ และต้องรันโค้ดที่ไม่น่าไว้ใจ
- **ให้โมเดลคัดลอกประโยคมาเป็นหลักฐาน แล้วจับคู่แบบยอมให้ต่างเล็กน้อย** ไม่เลือก ตามเหตุผลข้างบน
- **ใช้ Mermaid วาดแผนภาพ** ไม่เลือก เพราะไลบรารีใหญ่ 5.4 MB และแผนภาพของเรามีไม่เกิน 10 กล่อง จึงวาดเป็น HTML แทน ซึ่งยังได้เบราว์เซอร์ตัดบรรทัดภาษาไทยให้ด้วย
- **ใช้ ECharts วาดทุกอย่าง** ไม่เลือกสำหรับแผนภาพ เพราะ ECharts ตัดข้อความที่ไม่ใช่อักษรละตินทีละตัวอักษร ทำให้สระไทยหลุดจากพยัญชนะ ส่วนกราฟยังใช้ ECharts โดยตัดป้ายด้วย `Intl.Segmenter` ก่อนส่งให้ ECharts

## กติกาที่ตัวตรวจบังคับ (จากการลองกับรายงานจริง)

- ตัวเลขต้องปรากฏในข้อเท็จจริงที่อ้าง ระบบอ่านเลขไทยและจุลภาคหลักพันได้ ปีต้องอยู่ในข้อเท็จจริงเช่นกัน และนับทั้ง ค.ศ. และ พ.ศ.
- ปีในวงเล็บอ้างอิง เช่น "(Hinrichsen and Robey, 2000)" ไม่นับเป็นปีของเหตุการณ์
- กราฟเส้นต้องเป็นค่าตามปีที่อยู่ในข้อเท็จจริงของแต่ละจุด และห้ามเอาตัวเลขเดียวมาทำซ้ำเป็นเส้น เช่น ค่าเฉลี่ยช่วง 1990–1997 ไม่ใช่ค่าของปี 1990 กับปี 1997
- กราฟวงกลมที่ไม่ใช่ส่วนของผลรวมเดียวกัน จะถูกเปลี่ยนเป็นกราฟแท่ง
- "ข้อมูลปี" ของการ์ดตัวเลขต้องอยู่ในข้อเท็จจริง ศัพท์ในอภิธานศัพท์ต้องปรากฏในข้อเท็จจริงของมัน
- ขั้นตอนในแผนภาพอย่างน้อย 60% และแต่ละแถวของตารางเปรียบเทียบ ต้องมีคำตรงกับข้อเท็จจริงที่อ้าง
- เศษข้อความจากหน้าเว็บ (รูป ลิงก์ หัวข้อ markdown) และรายการเอกสารอ้างอิงของบทความ ไม่นำมาเป็นข้อเท็จจริง
- รายงานที่ไม่มีข้อความหลักฐาน (Agent Research) ใช้ประโยคในรายงานที่มี [n] แทน และไม่มีภาพที่เป็นตัวเลขเลย

## Consequences

- **สร้างเมื่อผู้ใช้กดขอ** (`POST /api/runs/{id}/visuals`) โดยเจ้าของ Run เท่านั้น
  - เรียกจาก API ไม่ผ่าน Worker ใช้โมเดลเร็ว (ADR 0006) ถ้าไม่ได้ตั้งไว้ใช้โมเดลหลักของ Run
  - เรียก 1 ครั้ง ถ้า JSON อ่านไม่ได้ขอซ่อมอีก 1 ครั้ง
  - เก็บเป็น `visuals.json` ข้าง `report.json` และผูกกับรายงานด้วย hash ขอครั้งต่อไปไม่เรียกโมเดลอีก
- **ไม่หักโควตา Run** มีเพดานต่อคนต่อวันแทน (`limits.visuals_per_day` ค่าเริ่มต้น 10 นับในตาราง `visuals_requests` จาก migration 0011) ส่วน token และค่าใช้จ่ายบวกเข้า Run นั้น
  - ลองกับ Gemini 3.1 Flash Lite: 2–12 วินาทีต่อรายงาน ราว $0.003 ต่อรายงาน
- **`report.json` ไม่เปลี่ยน** ตาม ADR 0005 เจ้าของซ่อนภาพได้ (`PATCH`) แต่แก้ข้อมูลในภาพไม่ได้
- **หน้าแบบโต้ตอบเป็น HTML ไฟล์เดียว** ต่อยอดจาก HTML export
  - กราฟวาดครั้งเดียวด้วย ECharts 6.1.0 (Apache-2.0, vendored) ใน Chromium ตัวเดียวกับที่พิมพ์ PDF โดยปิด network แล้วเก็บเป็น SVG
  - ไฟล์จึงเปิด offline ได้ พิมพ์คม และอ่านได้แม้ปิด JS
  - script ของเราราว 8 KB
  - ตัวเลือก "กราฟโต้ตอบเต็ม" ฝังไลบรารีด้วย ไฟล์ใหญ่ขึ้นราว 1.1 MB
- **ภาพที่ไม่ต้องใช้โมเดล** มีทุกรายงานแม้ยังไม่ได้สร้างภาพประกอบ ได้แก่ โครงเรื่อง แหล่งที่ถูกอ้างบ่อย และตารางแหล่งที่เรียงลำดับได้
- **ความปลอดภัย**
  - หน้ามี CSP ที่รันเฉพาะ script ของเราตาม hash และห้ามเรียก network ทั้งหมด
  - ในเว็บแอปเปิดผ่าน `/api/runs/{id}/interactive` ด้วย header `sandbox allow-scripts allow-popups allow-popups-to-escape-sandbox` ใน `<iframe sandbox>` ที่ไม่มี `allow-same-origin`
  - ผลทดสอบ: จากในกรอบเข้าถึงหน้าแอป cookie และ API ไม่ได้
- **HTML/PDF/Markdown export เดิมไม่เปลี่ยน** PDF ยังไม่มีภาพประกอบในรุ่นนี้
- **ข้อจำกัดที่รู้แล้ว:** ตัวตรวจยืนยันได้ว่าตัวเลข ปี และศัพท์อยู่ในข้อความต้นทาง แต่ยืนยันไม่ได้ว่าชื่อภาพหรือป้ายบรรยายตรงความหมายทุกคำ จึงลดความเสี่ยงด้วย prompt และให้ผู้อ่านกดเลขที่มาดูข้อความต้นทางได้ทุกค่า
