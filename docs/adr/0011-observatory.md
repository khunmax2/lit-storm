# Observatory: หน้าดูเอเจนต์ทำงาน แล้วดูแต่ละประโยคที่อ้างอิงคู่กับหลักฐาน

หน้า HTML ไฟล์เดียวที่แสดงการทำงานของ Run แบบ HUD ทำตามที่หัวหน้าขอเมื่อ 2026-10-11 ให้ทำหน้าดูการทำงานของ AI agent (อ้างอิง [AI-Agent-observatory](https://github.com/sakshigupta372/AI-Agent-observatory)) และ embed เป็น HTML ใน DeepLit หรือ Agenta ได้ ตัดสินใจเมื่อ 2026-10-15

## สิ่งที่ตัดสินใจ

1. **ใช้ข้อมูลจริงของ Run ไม่ใช้ข้อมูลจำลอง** prompt ตัวอย่างของหัวหน้าจำลอง stream ข้อมูล แต่ DeepLit มีข้อมูลจริงอยู่แล้ว
   - **เอเจนต์:** สร้างจาก event ของ Run ด้วยวิธีเดียวกับ canvas ของ MCP ([ADR-0010](./0010-mcp-app-canvas.md)): stage, usage และ note ประเภท perspectives / tree / flow / browsed
   - **เอกสารตรงกลาง:**
     - ระหว่างค้นคว้า แสดงสิ่งที่เอเจนต์ดึงเข้ามา: คำค้น มุมมอง แผน และหน้าเว็บที่อ่าน
     - เมื่อมีรายงานแล้ว แสดงตัวรายงาน แล้วไล่ทีละประโยคที่มีเลขอ้างอิง
   - **กรอบเรืองแสง:** `highlightRAGChunk(textToFind, actionLabel, color)` ตามที่ prompt ขอ
     - หา text ในเอกสาร แล้ววัดตำแหน่งด้วย `Range.getClientRects()` บรรทัดละกรอบ
     - วาดกรอบไว้ใน layer ที่เลื่อนไปกับเอกสาร และมีป้ายบอกงาน
     - ป้ายเปลี่ยนตามลำดับ: ดึงบริบท → ค้นหาความคล้าย [n] → มีหลักฐาน
   - **หลักฐาน:** คือข้อความที่ engine เก็บจาก Source นั้นใน `report.json` (`evidence`) และคำที่ซ้อนกับประโยคจะถูกทำเครื่องหมาย
   - **ตัวเลข "คำซ้อนกัน %":** วัดคำและตัวเลขที่ซ้อนกัน (ภาษาไทยใช้ 3 ตัวอักษรติดกัน) จึงเรียกว่า "lexical overlap" ไม่เรียกว่า similarity ของ embedding
     - ค่านี้ไม่ได้บอกว่าประโยคถูกหรือผิด
     - ถ้าแหล่งเป็นคนละภาษากับรายงาน ค่าจะต่ำแม้อ้างถูก
2. **ไฟล์เดียว ไม่มี library และไม่ขอข้อมูลจาก network**
   - ข้อมูลอยู่ใน `<script type="application/json">` และ `<` ทุกตัวในข้อมูลถูกเปลี่ยนเป็น `<` จึงปิด script ก่อนเวลาไม่ได้
   - ข้อความจาก Run หรือโมเดลขึ้นจอแบบ text เสมอ
   - CSP คือ `default-src 'none'` และให้รันเฉพาะ script/style ในไฟล์
3. **เปิดได้ 2 แบบ**
   - **สด** (`GET /api/runs/{id}/observatory`):
     - เปิดได้เมื่อ login แล้ว และต้องเป็นเจ้าของ หรือผู้ดูแลที่เจ้าของขอให้ช่วย (`deps.readable`)
     - เริ่มจาก event ที่มีแล้ว จากนั้นเรียก `GET /api/runs/{id}?after=` ทุก 2.5 วินาที พอ Run สำเร็จจึงดึง `/report` มาโยงหลักฐาน
     - CSP เพิ่มเฉพาะ `connect-src 'self'`
     - ในเว็บมีปุ่ม "ดูเอเจนต์ทำงาน" บนการ์ดของ Run ซึ่งเปิดในแท็บใหม่
   - **ไฟล์** (export รูปแบบ `observatory` ชื่อไฟล์ `<ชื่อรายงาน>.observatory.html`):
     - เล่นซ้ำเองโดยไม่ต้องต่อเน็ต
     - ส่วนค้นคว้ายาวราว 42 วินาทีที่ 1× ไม่ว่า Run จริงจะนานแค่ไหน
     - มีปุ่ม หยุด / เริ่มใหม่ / 1–8× / ข้ามไปที่รายงาน
     - ดาวน์โหลดได้จากเมนูดาวน์โหลดในหน้ารายงาน และจาก `research_export(format="observatory")` ของ MCP
     - Agenta เปิดไฟล์นี้ใน Files ได้ เพราะ iframe ของ Agenta อนุญาต script ในไฟล์ (`allow-scripts`)
4. **ส่ง event เฉพาะที่เจ้าของเห็นอยู่แล้ว** traceback และ note ที่หน้า Run ไม่แสดง จะไม่ใส่ในหน้านี้

## ทางเลือกที่ไม่เลือก

- **ใช้ repo AI-Agent-observatory ตรงๆ:**
  - เป็น Astro + React + three.js ที่ต้องมี Groq, Tavily และ Postgres ของตัวเอง
  - ดูการทำงานของเอเจนต์ตัวเดียวที่ repo นั้นเขียนเอง ไม่ได้อ่าน event ของเรา
  - README บอกว่าใช้ MIT แต่ไม่มีไฟล์ LICENSE
  - จึงเอาแค่แนวคิดและหน้าตามาใช้ ไม่ได้เอาโค้ดมา
- **ภาพ 3D:** ต้องมี library ขนาดใหญ่ ขัดกับข้อ 2 และในกรอบของ Agenta อ่านยากกว่า 2D
- **รวมเข้ากับ canvas ของ MCP:** canvas ต้องเล็กเพื่ออยู่ในแชตของ host ส่วน observatory ต้องใช้ทั้งจอ จึงแยกกันแต่ใช้วิธีอ่าน event แบบเดียวกัน

## การทดสอบ

- `tests/test_observatory.py`
  - ข้อมูลอยู่ในหน้าครบ, ไม่มีการโหลดอะไรจาก URL, CSP ของไฟล์ไม่มี `connect-src`
  - ข้อความแบบ `</script>` ในหัวข้อ รายงาน หรือ event ปิด script ไม่ได้
  - ส่งเฉพาะ note ที่เจ้าของเห็น
  - หน้าสดเปิดได้เฉพาะเจ้าของ คนอื่นได้ 404
  - ไฟล์ดาวน์โหลดได้ทั้งจากเว็บและผ่าน `research_export`
- ดูด้วยตาบนเครื่องนี้เมื่อ 2026-10-15 ด้วย Run จริง 3 แบบ
  - STORM: 44 ประโยคจาก 18 แหล่ง
  - Deep Research: เอเจนต์ 21 ตัว 23 ประโยค
  - Agent Research: เห็นเอเจนต์ค้นหาเกิดทุกรอบ
  - ไม่มี error ใน console

## จะกลับมาพิจารณาเมื่อ

- engine เก็บว่าประโยคไหนมาจากข้อความตอนไหนของหน้าเว็บ: ตอนนั้นจึงแสดงการจับคู่จริงแทนการวัดคำที่ซ้อนกัน
- ต้องการให้หน้าสดได้ข้อมูลทันทีโดยไม่ poll: ให้เปลี่ยนไปใช้ SSE `/api/runs/{id}/live` ซึ่งต้องมี cookie อยู่แล้ว
