# ภาพ 3D ของเอเจนต์ใน STORM และโต๊ะสนทนาของ Co-STORM

Deep Research และ Agent Research มีภาพการทำงานบนการ์ดของ Run อยู่แล้ว (แผนผังการค้นคว้า และขั้นตอนการค้นคว้า) แต่ STORM และ Co-STORM ยังไม่มี เจ้าของงานให้นำแนวทางของ [AI-Agent-observatory](https://github.com/sakshigupta372/AI-Agent-observatory) มาแสดงงานแบบหลายเอเจนต์ใน STORM และ Co-STORM ตัดสินใจเมื่อ 2026-10-15

## สิ่งที่ตัดสินใจ

1. **ภาพ 3D ใน web app ใช้ React Three Fiber** (`three` 0.186.1, `@react-three/fiber` 9.8.1, `@react-three/drei` 10.7.9 ระบุรุ่นตายตัว)
   - ภาพประกอบด้วยแกนเรืองแสงที่เกิดขึ้นตามงาน เส้นโค้งเชื่อม ก้อนข้อมูลวิ่งตามเส้น และแหล่งข้อมูลที่อ่านแล้วโคจรรอบจุดค้นเว็บ
   - โค้ดเขียนใหม่ทั้งหมด ไม่ได้คัดลอกมา เพราะ repo ต้นแบบไม่มีไฟล์ LICENSE (README บอกว่า MIT) ส่วนสำเนาที่ clone ไว้ดูอยู่ที่ `deep_research_lit/AI-Agent-observatory`
   - โหลดแบบ `React.lazy` เฉพาะตอนผู้ใช้เปิดดู ไฟล์แยกขนาดราว 260 KB (gzip) และหน้าอื่นไม่โตขึ้น
   - ป้ายชื่อเป็น DOM ที่คำนวณตำแหน่งจาก 3D ทุกเฟรม ไม่ใช้ `Html` ของ drei เพราะบางป้ายไม่ขึ้นเมื่อแกนเกิดพร้อมกับ scene และไม่ใช้ `Text` ของ drei เพราะโหลดฟอนต์จาก CDN และไม่มีอักษรไทย
2. **STORM** (การ์ดของ Run หัวข้อ "ดูเอเจนต์แบบ 3D")
   - ข้อมูลมาจาก event ของ Run ชุดเดียวกับที่หน้า Run ใช้ ทั้งระหว่างที่งานวิ่ง (`useRunLive`) และตอนเล่นซ้ำ
   - มุมมอง (note `perspectives`) เกิดเป็นเอเจนต์ทีละตัว แต่ละตัวถามผู้เชี่ยวชาญหัวข้อ ซึ่งไปค้นเว็บ
   - ทุก note `browsed` มีก้อนข้อมูลวิ่งจากมุมมองไปหาผู้เชี่ยวชาญ จากผู้เชี่ยวชาญไปที่เว็บ แล้ววิ่งกลับ และแหล่งที่อ่านแล้วจะเพิ่มขึ้นรอบจุดค้นเว็บ
   - stage outline / article / polish / normalize ทำให้ผู้วางโครงเรื่อง ผู้เขียนแต่ละหัวข้อ ผู้เกลา และรายงาน เกิดขึ้นตามลำดับ
3. **Co-STORM** (หน้า Discussion หัวข้อ "โต๊ะสนทนา · 3D")
   - ข้อมูลมาจาก `view` ของ Discussion ที่หน้าใช้อยู่แล้ว ได้แก่ ผู้เข้าร่วม คำพูด แหล่งที่อ้าง และผังความคิด
   - ผู้ดำเนินรายการ ผู้เชี่ยวชาญ ผู้เชี่ยวชาญช่วงอุ่นเครื่อง และ "คุณ" นั่งรอบโต๊ะ มีคลังความรู้อยู่กลางโต๊ะ ผังความคิดเป็นกลุ่มดาวด้านบน และเว็บอยู่ด้านล่าง
   - เล่นทีละคำพูด: คนพูดเรืองแสงและคำพูดขึ้นในกรอบ แหล่งที่อ้างวิ่งจากเว็บมาหาคนพูดก่อน แล้วคนพูดส่งสิ่งที่ได้เข้าคลังความรู้
   - ระหว่างที่รอบใหม่ทำงาน หน้าเว็บที่อ่านจะวิ่งจากเว็บเข้าคลังความรู้ เมื่อรอบจบจะเล่นเฉพาะคำพูดใหม่
4. **มีปุ่มหยุด และเล่นซ้ำ** ภาพหมุนรอบเองช้าๆ ลากหมุนหรือซูมได้ คลิกที่เอเจนต์เพื่อดูชื่อและคำอธิบายเต็ม ถ้าเบราว์เซอร์ปิด WebGL จะแสดงข้อความแทน

## ทางเลือกที่ไม่เลือก

- **ใช้ repo ต้นแบบทั้งตัว:** repo นั้นจำลองเอเจนต์ตัวเดียวจาก Groq, Tavily และ Postgres ของตัวเอง และใช้ Astro ไม่ได้อ่านข้อมูลของเรา
- **ใส่ภาพ 3D ในไฟล์ Observatory ([ADR-0011](./0011-observatory.md)):** ไฟล์นั้นตั้งใจไม่มี library และเปิดได้ทุกที่ ถ้าเพิ่ม three.js เข้าไปขนาดจะโตราว 1 MB
- **ใช้ postprocessing (bloom):** ต้องเพิ่ม dependency และหนักบนเครื่องที่ไม่มี GPU จึงใช้ทรงกลมโปร่งแสงแบบ additive ทำแสงเรือง

## การทดสอบ

- `tsc` และ `vite build` ผ่าน
- ดูด้วยตาบนเครื่องนี้เมื่อ 2026-10-15 (Chromium headless ใช้ SwiftShader) ไม่มี error ใน console
  - STORM โซลาร์เซลล์: เห็นมุมมอง 5 ตัว ผู้เชี่ยวชาญ การค้นเว็บ ผู้เขียนตามลำดับ และรายงาน
  - Co-STORM โซลาร์เซลล์: 19 คำพูด ผู้เชี่ยวชาญ 3 คน 12 หัวข้อในผังความคิด
- ยังไม่ได้ดูระหว่างที่ Run จริงกำลังทำงาน ส่วนเส้นทางของข้อมูลสดใช้ `useRunLive` ตัวเดียวกับภาพอีกสองแบบ
