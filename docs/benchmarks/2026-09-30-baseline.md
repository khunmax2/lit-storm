- **SearXNG**: สำเร็จ 1 ใน 4 เพราะ engine ภายนอก (Brave, Google CSE) ระงับ IP นี้ว่า "too many requests" และ DuckDuckGo timeout — Run ที่สำเร็จใช้ **85 วินาที** ($0.017) ผลวันนี้จึงใช้เป็นเส้นฐานของ SearXNG ไม่ได้ ต้องวัดซ้ำเมื่อพ้นการระงับ หรือใช้บริการค้นหาที่เสถียรกว่า
