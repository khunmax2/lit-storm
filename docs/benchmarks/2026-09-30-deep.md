## สิ่งที่ต้องแก้ระหว่างทาง

- **`getLanguageModel`:** `lib/core` เรียกใช้โดยไม่ import เพราะ Nuxt import ให้อัตโนมัติ นอก Nuxt จึงไม่มี เพิ่ม import ตรงใน fork แล้ว
- **stdin:** CLI ถือว่า stdin ที่ปิดแปลว่า process แม่ตายแล้ว ตอนทดสอบด้วย `echo | node` จึงจบทันที ฝั่ง Engine เปิด stdin ค้างไว้
- **nginx ข้างหน้าตอบ 502 หลัง web container ถูกสร้างใหม่:**
  - nginx resolve ชื่อ `web` ครั้งเดียวตอนเริ่ม จึงยังส่งไปที่อยู่เดิม
  - แก้ให้ resolve ใหม่ผ่าน resolver ของ Docker ทั้งที่ nginx ข้างหน้า (`web`) และใน image เว็บ (`api`)
