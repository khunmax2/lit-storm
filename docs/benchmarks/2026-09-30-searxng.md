# SearXNG หลังปรับ engine (2026-09-30)

ค่าตั้งและเครื่องที่ใช้วัดเหมือน [เส้นฐาน](2026-09-30-baseline.md): ระดับมาตรฐาน, Gemini 3.1 Flash Lite ทุกขั้น, stack ในเครื่อง dev

**สิ่งที่เปลี่ยน**
- เปิด Google, Bing และ Yahoo ในหมวด general ของ SearXNG เป็นตัวสำรองให้ Brave, DuckDuckGo และ Google CSE
- เพิ่ม Search Provider "SearXNG LDR-academic" ซึ่งถาม SearXNG ตัวเดิม แต่ใช้เฉพาะ engine วิชาการ (arXiv, Crossref, Europe PMC, Google Scholar, OpenAIRE, OpenAlex, PDBe, PubMed, Semantic Scholar)

**สรุป**
- **SearXNG สำเร็จ 2 ใน 2** รวมหัวข้อไทยที่ล้มเหลวในเส้นฐาน ใช้ **85–89 วินาที** ($0.025–0.027) ได้แหล่งอ้างอิง 45 รายการสำหรับหัวข้ออังกฤษ (เส้นฐานได้ 24) และ 18 รายการสำหรับหัวข้อไทย
- **SearXNG LDR-academic** ใช้ **66 วินาที** กับหัวข้ออังกฤษ ได้แหล่งอ้างอิง 46 รายการ เร็วกว่า arXiv ตรง (226 วินาที) ราว 3.4 เท่า เพราะไม่ต้องเว้น 3 วินาทีต่อคำค้นตามที่ arXiv กำหนด ใช้ token ขาเข้ามากกว่า เพราะบทคัดย่อยาวกว่า snippet จากเว็บ
- ไม่ได้วัดหัวข้อไทยกับ LDR-academic เพราะ engine วิชาการแทบไม่มีเนื้อหาภาษาไทย ตอนทดสอบด้วยมือ มีแค่ Google Scholar ที่ตอบกลับ
- ยังใช้เวลาเริ่ม process 9 วินาทีทุก Run
