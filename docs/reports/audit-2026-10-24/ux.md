มุมผู้ใช้: หลัง "กู้คืน" แล้วเห็นหน้าว่าง ไม่รู้ว่ารายงานหายหรือยังอยู่ และถ้า Run หมด 30 วันก่อน Session จะถูกลบถาวรโดยที่ผู้ใช้ไม่เคยเห็นว่ามันนับถอยหลังอยู่ (ข้อความนี้ลงเป็นข้อสังเกต ไม่ใช่บั๊ก)

**วิธีแก้ที่เสนอ:** ตัวเลือก (เจ้าของเลือก): (ก) กู้ Session แล้วพา Run ที่ถูกลบพร้อมกันกลับมาด้วย, (ข) ในหน้า Session ที่ว่าง แสดงข้อความ "มี 1 Run อยู่ในถังขยะ กู้คืน" และกล่องค้นคว้า · ขนาด: เล็กถึงกลาง

## ข้อสังเกตเล็ก (ไม่ลงเป็นข้อ)

- ถังขยะที่ว่างแสดง `trash.lead` สองครั้ง (ใต้หัวข้อหน้าและเป็นคำอธิบายของกล่องว่าง)
- รูปพหูพจน์อังกฤษ "1 sections set" (ข้อ 3 ของผลตรวจคำแปล)
- caption ภาษาอังกฤษของโหนดแผนภาพ Agent flow ปนกับหัวข้อที่แปลแล้ว
- หน้าสถานะระบบแสดงข้อความ error ดิบของผู้ให้บริการในกล่อง monospace ยาวหลายบรรทัด (ตั้งใจ: ผู้ดูแลต้องใช้ แต่ไม่ตัดให้สั้นหรือพับ)
- หน้าแรกของบัญชีที่โควตาหมด: ข้อความ "โควตาเดือนนี้หมดแล้ว" ขึ้นสีส้มเล็กใต้กล่องและปุ่มส่งเป็นสีจาง ผู้ใช้ไม่ได้เห็นก่อนพิมพ์ (ดู UX-17 สำหรับสี)

## รายการที่ตรวจแล้วไม่พบปัญหา

- ธีมมืดและสว่างสม่ำเสมอ ไม่พบองค์ประกอบที่ไม่เปลี่ยนสี (ตรวจภาพ Co-STORM, โปรเจกต์, สถานะระบบ ชุดมืด) ปัญหาสีของชุดมืดมีเพียง 24 จุดใน UX-17
- ที่ 1024x768 ไม่มีหน้าใดล้นแนวนอน; ที่ 1440 เลย์เอาต์ปกติทุกหน้า
- สถานะว่างของบัญชีใหม่ (หน้าแรก, งานวิจัยทั้งหมด, โปรเจกต์, ถังขยะ) อ่านเข้าใจและมีทางไปต่อ
- สถานะโหลดของ 5 หน้ารายการแสดง skeleton ถูกต้อง (ปัญหาอยู่ที่สถานะ error ดู UX-11)
- ภาษา: `lang` ไทย/อังกฤษสลับครบทั้งหน้า ไม่พบข้อความไทยปนอังกฤษที่ลืมแปล (นอกจากรายการใน "ผลตรวจคำแปล")
- ข้อสงสัย e-S10 ส่วน B ข้อ (2) "ข้อความ ลิงก์ไม่ถูกต้อง โผล่หลังตั้งรหัสผ่านสำเร็จ": ทำซ้ำไม่ได้ (ดู BUG-58)
